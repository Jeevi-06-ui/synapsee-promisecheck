## Overview

PromiseCheck is an automated auditing tool designed to verify that public web applications honor their published claims and commitments. It uses **TinyFish autonomous web agents** to visit target websites remotely, inspect content, and assess adherence to promise contracts.

---

## Local Laptop Execution

PromiseCheck initially runs locally on your laptop:

```bash
# 1. Install dependencies (Node standard library is used, zero external npm deps needed)
cd apps/promisecheck

# 2. Configure environment (optional)
cp .env.example .env

# 3. Run audit against the café's public URL
npm run check -- --url https://<your-public-cafe-url>
```

---

## 🌐 TinyFish Cloud Reachability Contract

> [!WARNING]
> TinyFish's browser agents execute in remote cloud environments.
> If you pass `http://localhost:3000`, TinyFish cannot resolve your local Mac's loopback address.
> Always pass a **public URL** generated by a tunnel (e.g. `npx localtunnel --port 3000`) or cloud deployment.

---

## Architecture & Decoupling

PromiseCheck does **not** connect to the Café via:
- Shared database
- Internal REST / GraphQL APIs
- Direct code imports

Instead, PromiseCheck treats the Café as a complete black-box, verifying only what a real visitor or automated TinyFish agent sees on the public website.

---

## Defined Promises

The default promise specifications are stored in `src/promises.json`:
- **100% Organic & Fair-Trade Coffee**
- **Fresh Daily Bakes by 7:00 AM**
- **Dedicated Gluten-Free Kitchen Station**
- **Open 7 Days (7:00 AM – 9:00 PM)**
- **Complimentary Gigabit Wi-Fi**
- **100% Satisfaction Remake Guarantee**
